2. Pelan Deployment Enterprise

Penyebaran Peringkat Pengeluaran (Production)

Disarankan menggunakan platform pelayan tanpa server (*serverless*) seperti Vercel, Netlify, atau Cloudflare Pages untuk kebolehcapaian statik terpantas global (CDN).

Automasi CI/CD

Konfigurasikan talian paip automatik menerusi GitHub Actions untuk menguji kod secara linting dan membina projek statik vite build pada setiap penghantaran (git push) ke cawangan main.

Sekuriti & SSL

Semua data harus dihantar secara selamat menerusi protokol HTTPS. Integrasikan pengepala Content Security Policy (CSP) untuk menghalang serangan eksploitasi silang tapak (XSS).

3. Spesifikasi Mock API (RESTful JSON)

Sistem ini sedia diintegrasikan dengan API standard kebangsaan. Di bawah ialah contoh struktur respons JSON daripada panggilan endpoint API Kebolehpasaran:
